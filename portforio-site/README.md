# portforio-site
HTML・CSS・JavaScriptを用いて作成した、私のポートフォリオサイトです。

## Demo
https://ai9098.github.io/Web-site/portforio-site/

## Features
- Home/ About/ Project/ Contactのページを作成
- javascriptを用いたモーダル機能
- スクロール時のアニメーション
- 制作物詳細ページへのリンク機能
- FormSubmitを利用したお問い合わせフォーム
- 見やすいデザイン

## Technologies Used
- HTML
- CSS
- JavaScript
